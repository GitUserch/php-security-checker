# 🛡️ PHP Security & Vulnerability Checker

Инструмент для экспресс-проверки серверов и сайтов на наличие критических уязвимостей в PHP (включая RCE-векторы и небезопасные конфигурации).

---

## 🚨 Зачем это нужно?

В ядре PHP и механизмах обработки сессий обнаружены критические уязвимости выполнения произвольного кода (RCE). Если ваша версия PHP устарела или в ней включены опасные настройки, сервер находится под угрозой взлома.

Этот репозиторий содержит простые и безопасные скрипты для быстрой диагностики.

---

## 🚀 Как использовать

### Вариант 1: Для владельцев сайтов (Веб-интерфейс)

1. Скачайте файл `security_check.php` из этого репозитория.
2. Загрузите его в корневую папку вашего сайта (например, `public_html`).
3. Откройте в браузере: `https://ваш-сайт.com/security_check.php`
4. Посмотрите результат проверки.
5. **Важно:** Удалите файл `security_check.php` с сервера сразу после проверки!

---

## 🛠 Безопасные версии PHP

Для полной защиты ваша система должна быть обновлена до следующих версий:

- **PHP 8.5** ➔ `8.5.12` или выше
- **PHP 8.4** ➔ `8.4.27` или выше
- **PHP 8.3** ➔ `8.3.36` или выше
- **PHP 8.2** ➔ `8.2.35` или выше

> ⚠️ Все версии PHP 8.1 и ниже официально сняты с поддержки (EOL) и требуют срочной миграции на поддерживаемые ветки.

---
